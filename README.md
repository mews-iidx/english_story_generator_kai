# StoryKai (英語読解＆弱点語彙定着リーダー)

Gemini APIと忘却曲線（Anki風SRS）を活用した、パーソナライズ英語読解PWAアプリです。

## 🌟 特徴
- **A1〜C1 レベル対応**: 中学初級英語から上級まで、自分の実力に合わせたショートストーリーを生成。
- **忘却曲線（間隔反復）連動**: 読めなかった単語や構文パターンが、次回以降のストーリーに自然な応用文として自動再登場。
- **全単語タップ & スマホChrome風ボトムシート翻訳**: Google翻訳（完全無料・待ち時間ゼロ）で瞬時に訳と発音を確認。
- **構文パターンの応用出題**: `too ... to ...` などの文法構文を登録すると、型を活かした新しいシチュエーションで再出題。
- **個人DB / 端末間同期対応**: LocalStorageに加え、Google Drive / スプレッドシート連携（BYOD）に対応。
- **PWA対応**: スマホのホーム画面に追加してスタンドアロンアプリとして利用可能。

## 🚀 開発環境の起動
```bash
docker compose up -d
```
ブラウザで `http://localhost:5173/` にアクセス。

## 📦 ビルド
```bash
npm run build
```
